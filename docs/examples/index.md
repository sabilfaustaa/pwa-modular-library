# Contoh Interaktif

Kumpulan demo langsung (live) yang menunjukkan setiap composable & utilitas library bekerja di peramban. Tiap contoh menyertakan kode sumber yang bisa langsung disalin.

> Demo dijalankan sepenuhnya di sisi klien (`<ClientOnly>`) dan **fail gracefully** — jika peramban tidak mendukung suatu fitur, demo tetap tampil dengan flag `isSupported`.

## Daftar contoh

| Contoh | Composable / Utilitas |
|---|---|
| [Status PWA & Update](/examples/pwa-status) | `usePWA` |
| [Install Prompt (A2HS)](/examples/install-prompt) | `useInstallPrompt` |
| [Notification Playground](/examples/notifications) | `useNotifications` |
| [Konfigurasi Cache & count()](/examples/cache-config) | `useCacheConfig` |
| [Form Offline + Antrean Sync](/examples/background-sync) | `useBackgroundSync` |
| [Generator sw.js](/examples/generate-sw) | `generateSW` |
| [Validator Manifest](/examples/validate-manifest) | `validateManifest` |
